# Jingyi Fang — Economics Website

A single-page academic website containing research, teaching, and contact information.

## Edit
- `index.html`: all website content.
- `assets/style.css`: fonts, colors, spacing, and layout.
- `assets/portrait.jpg`: profile photo.

Open `index.html` in a browser to preview. No installation or build step is required.

The additional HTML files redirect earlier page addresses to the relevant section of the single-page website.

## GitHub Pages
Upload these files to the repository root. Under Settings → Pages, select Deploy from a branch, choose the main branch and /(root), and save.

For a personal site at https://USERNAME.github.io, name the repository USERNAME.github.io, replacing USERNAME with your GitHub username.
